# AI-Powered-Healthcare-Assistant
Built a Tars-based conversational AI agent integrated with a hospital knowledge base and Salesforce CRM for patient support, appointment booking, and automated lead generation.

Tech Stack: Tars AI, Salesforce, Knowledge Base, LLM
1 Aug 2026- 2 Aug 2026

Developed an AI-powered healthcare chatbot using the Tars AI platform for a multi-specialty clinic to automate patient interactions.
Built a conversational workflow that distinguishes between new and existing patients, providing personalized assistance.
Integrated a Knowledge Base trained on hospital website content to answer questions about doctors, specialties, treatments, services, insurance, and locations.
Designed an appointment booking workflow that collects patient details and creates Salesforce Leads for follow-up.
Implemented conversational AI for healthcare queries while ensuring responses remained within the hospital knowledge base and encouraged professional consultation for medical concerns.
Improved user experience through structured conversation flows, knowledge retrieval, and CRM integration.
